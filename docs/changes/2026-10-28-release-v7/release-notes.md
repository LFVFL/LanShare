# LanShare v7.0

Windows x64 单文件版本。下载附件 `lanshare.exe`，不需要安装 Python，也不需要额外放置 Qt
或源码。升级前请退出旧版本（包括系统托盘）；聊天记录和原有设置不做迁移或清空。

## 本次更新

- 桌面窗口标题与界面内版本号统一为 `v7.0`；手机聊天室的“修改群名”移到顶部。
- 文件搜索支持仅当前目录、当前目录及子目录、整个共享目录；在共享根目录合并重复范围。
- 预览按钮与下载按钮相邻；修复可预览文件误变下载，并保留主动内容按附件下载的保护。
- 聊天图片使用原图和二进制分片上传，不再设置固定 5MB 门槛；包含 PNG、JPEG、GIF、WEBP、
  BMP、TIFF、ICO、HEIF/HEIC 和 AVIF 支持，仍保留磁盘、像素及并发保护。
- 默认群和其他群支持改名；修复群聊表头对齐，移除输入区下方的常驻说明。
- 粘贴纯文本保留换行、空格与缩进；发送失败保留草稿，重试避免重复发送。
- 完善单实例与右键菜单：未启动时启动网盘，已启动时切换共享目录；修复相关生命周期问题。
- 单文件使用独立用户临时解包目录，修复原交付 EXE 低完整性标记引起的临时目录创建失败；
  不要求管理员运行，不修改整个目录的权限。
- 禁用 Web 请求在主机上执行文件，加强路径/Junction 边界及切换共享后的旧 ZIP 隔离。
- 修正群名嵌入转义、长连接安全响应头与 multipart 上传完整性检查。
- 完善聊天删除/清空的 SSE 同步、文件分页全局排序、批量删除失败提示及构建/测试隔离。

## 说明

本版本同时整合前轮选定的 P1/P2 修复；密码日志及明文设置按明确要求保留，原审查
“其他改进建议”不在实施范围内。日志可能包含完整密码，请勿对外公开。详细范围、测试
边界与逐项记录见仓库 `docs/changes/`。EXE 只作为 Release 附件，不加入源码历史。真实聊天、设置、原始日志与
本机权限诊断不公开，也不随发布打包。

手机界面已在真实 Chrome 的桌面/移动视口验证；实际手机输入法、Safari/WebView 及所有
Windows 环境仍可能有差异。若升级后仍看到旧版本，请确认已退出托盘里的旧进程再启动新文件。
右键菜单文字依赖正常启动/退出时的状态同步，强制结束或崩溃后可能暂时保留旧文字；
点击时仍由单实例处理实际启动或目录切换，不把静态菜单文字当作实时进程探测。
