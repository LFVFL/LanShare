# LanShare v7.0.1

Windows 单文件版本，不需要安装 Python。这个版本重点修复 v7.0 在部分电脑上因无法创建
自定义临时解包目录而启动失败的问题，并分别提供 Windows 10/11 常规包和 64 位
Windows 7 SP1 候选包。

升级前请退出旧版本，包括系统托盘中的进程；设置和聊天记录不会迁移或清空。

## 本次更新

- 移除 v7.0 强制使用的 `%LOCALAPPDATA%\LanShare\Temp` 解包路径，恢复 PyInstaller
  与 Windows 的默认临时目录选择。
- 正常退出后仍由 bootloader 清理本次 `_MEI*` 解包目录；不要求管理员运行，也不修改
  系统环境变量或目录权限。
- 窗口标题、界面、Qt 应用和网页版本统一为 `v7.0.1`。
- 保留 v7.0 的文件预览与下载、递归搜索、聊天原图分片上传、群聊改名、纯文本换行和
  单实例右键菜单等修复。
- 密码日志和明文设置按现有要求保持原状；日志可能包含完整密码，请勿对外公开。

首次双击确认。Python 3.8 已停止安全更新，此包仅用于旧系统兼容。

两个 EXE 均未做数字签名，Windows SmartScreen 或安全软件可能提示未知发布者。下载后
请先核对 SHA-256，不要通过关闭系统安全功能来强行运行。

## 验证说明
