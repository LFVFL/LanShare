# LanShare v7.0.2

Windows 单文件版本，不需要安装 Python。这个版本修复文件页网格模式下文件夹无法进入的
问题，并重新整理网格卡片布局。

升级前请退出旧版本，包括系统托盘中的进程；设置和聊天记录不会迁移或清空。

## 本次更新

- 文件夹卡片支持点击图标区、名称或卡片空白处进入目录。
- 复选框和预览、下载、更多操作不会误触目录跳转。
- 文件夹入口支持键盘 Tab 聚焦和 Enter 打开。
- 卡片统一最小高度、两行标题预留和底部操作栏，补充类型、大小及修改时间。
- 桌面卡片调整为更舒展的比例；手机保持两列布局，320px 和 390px 均无横向溢出。
- 窗口、Qt、网页和打包版本统一为 `7.0.2`。
- 保留 v7.0.1 的默认临时解包机制、聊天图片、预览下载、搜索、群聊改名和单实例修复。
- 密码日志和明文设置按现有要求保持原状；日志可能包含完整密码，请勿对外公开。
